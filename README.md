# CYB433 Group 6 — Tourism Ticketing Portal (`TourismTicketingPortal.sol`)

Smart contract implementation for **Use Case 6: Tourism Ticketing Portal**, enforcing time-slot capacity limits, single-entry gate validation to prevent ticket reuse, anti-scalping transfer price caps and transfer limits, and off-chain PII protection via commitment hashes.
